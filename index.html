First, meet the board

A small board with lots of ways in

The Sense HAT sits on the Raspberry Pi's 40-pin GPIO header. Its centre is an 8×8 matrix of 64 RGB LEDs: each square mixes red, green and blue light, so it can show colours, scrolling messages and simple animations.

There is a five-way joystick for simple input, too. Temperature, humidity and pressure sensors can help a project respond to its surroundings; the accelerometer, gyroscope and magnetometer can make it respond to movement and orientation. We will focus on the display in this lab, and leave the other sensors as ideas for later.

For hardware details, see the Raspberry Pi Sense HAT documentation.

A project with a space story

From classroom experiments to orbit

Astro Pi is an education programme that gives students opportunities to design and run experiments connected with the International Space Station. Raspberry Pi Foundation's 2017 report describes Astro Pi units in the station's Columbus module. In an update on 22 April 2026, ESA said 387 teams had earned flight status in the 2025/26 challenge and that the first programmes were scheduled to run on the ISS that week. These are Astro Pi computers and programme activities; that is not a claim that a standalone Sense HAT board is currently aboard the station.

The two-hour journey

Four small steps, one shared performance

Take the activities in order. Each one adds a new way to use the kit; the last one reuses what you have made.

01

First contact · task1_verify.py

Is the Sense HAT listening?

Run the short check. One gold LED should appear near the centre of the matrix, then switch off. This confirms that the Pi can talk to the board. No scrolling and no sound yet.

What to notice

The matrix has 8 columns and 8 rows. The script lights just one coordinate using an RGB colour, then clears the display.

Hardware
02

Make something for the display · task2_display_and_art.py

Give the tiny screen a winter scene

Choose a greeting and its colours, then draw an 8×8 picture in Pixel Studio. Start from a template or make your own. Copy the generated Python list into TODO 2 in the task file and run it on the Pi.

Open the browser Pixel Studio or run python3 pixel_studio_gui.py on the Pi.

Why exactly 64 colours?

The matrix has 8 rows × 8 columns. The generated list is row-major: the first 8 entries are the top row, then the next row, down to the bottom.

Display
03

Make a chime · task3_music_tones.py

Shape a sound, one note at a time

This activity is about sound; it does not use the Sense HAT. NumPy builds a digital tone from samples of a sine wave, and Pygame sends the samples to the speaker. A quieter octave overtone and a decaying envelope help the tone sound more like a bell.

Frequency (Hz)Sets pitch. A higher frequency sounds higher; doubling it raises the pitch by an octave.
Beat countSets note length. Two beats lasts twice as long as one beat; a REST occupies time without a tone.
Tempo (BPM)Scales the beat: one beat lasts 60 ÷ BPM seconds.

Choose a melody in selected_melody_name: Winter Bells, Galway Winter Chime, Snowfall or Bell Echo. Then change notes, beat lengths or tempo and listen again.

Quick note guide

A4 = 440 Hz · C5 = 523.25 Hz · G5 = 783.99 Hz · 0.5 beat = eighth note · 1 beat = quarter note · 2 beats = half note.

Sound
04

Bring lights and sound together · task4_winter_bells_symphony.py

Make a little Winter Bells symphony

Reuse your ideas from the display and music tasks. Change the melody sections, add to the snow scene or reuse your pixel art, and write a closing message. Can your group make each light scene distinct enough for another group to guess what is happening?

How the parts stay together

The programme coordinates its LED scenes and music against elapsed time, so the display can change along with the performance.

Get the Raspberry Pi ready

Allow about 10 minutes for setup. Extract the lab folder on the Pi, open a terminal, and run:

● ● ●Terminal
cd ~/winter_bells_lab
chmod +x setup_pi.sh
./setup_pi.sh

The setup script checks for sense_hat, pygame, numpy and tkinter. Open the task files in Thonny or Geany. In Geany, set Execute to python3 "%f".

Before you leave

  • Stop a running task with Ctrl+C or Thonny's Stop button.
  • If LEDs remain on, run sense.clear().
  • If there is no sound, check the Raspberry Pi desktop audio menu and select HDMI or your headphones/speakers.
  • If Pixel Studio reports an invalid image, check that it has exactly 64 pixels: eight rows of eight.
